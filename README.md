# akaucybersec.github.io

Personal cybersecurity portfolio site, built with Jekyll on GitHub Pages using
the [Hacker theme](https://github.com/pages-themes/hacker).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Visit `localhost:4000` to preview.

## Structure

- `index.md` — homepage content (bio, skills, projects, contact)
- `_config.yml` — site title, description, theme settings
